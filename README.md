A ginger kitten waving hello while hugging its teal plush fish. The program copies that picture,
byte for byte, to the output directory as `entry.png` for make.fun's Draw the cutest cat bounty.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

No dependencies, Node 22 standard library only. The picture is the whole entry: the run writes
the same 949,891 bytes every time, so the two graded runs match exactly.
